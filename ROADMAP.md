## ✅ Fonctionnalités Déjà Déployées (v1.0)
- [x] **Riot ID Account-V1** : Conversion de tous les pseudos avec tags et caractères spéciaux (ex: `8ï8`).
- [x] **Pagination & Intersection MATCH-V5** : Extraction des parties communes en équipe via calcul d'ensemble Python.
- [x] **Algorithme d'Affinité 100 Pts** : Calcul sur Winrate, Synergie KDA, Complémentarité des Rôles & Duo Champions.
- [x] **Archétypes Personnalisés** : Génération automatique du profil psychologique du duo.
- [x] **Avatars Officiels DataDragon** : Affichage des icônes réelles des champions joués.
- [x] **Multilingue (FR 🇫🇷 / EN 🇬🇧)** : Bascule instantanée de la langue.
- [x] **Export Carte PNG** : Génération et téléchargement d'une carte d'affinité haute définition.
- [x] **Design Mobile & Responsive** : Optimisation iOS/Android et esthétique Rose & Cyan Hextech.

## 🔮 Nouvelles Fonctionnalités Proposées (Roadmap v2.0)

### 1. ⚔️ Mode Némésis / Rivalité ("Rivals Mode")
> Analyser les parties où les deux joueurs étaient **dans des équipes opposées** (L'un contre l'autre).
- Calcul d'un **Score de Rivalité & Domination** (Qui gagne le plus souvent contre l'autre ?).
- Statistiques de solokills directs (Nombre de fois où le joueur A a éliminé le joueur B).

### 2. 🎮 Sélecteur de Mode de Jeu
> Permettre de filtrer les parties selon la file de jeu :
- Ranked Solo/Duo uniquement
- Ranked Flex
- Mode ARAM
- Mode Arena 2v2v2v2 (Compatibilité spéciale Arena)

### 3. 🔗 Liens d'Affinité Permanents & Partageables
> Pouvoir partager un lien direct d'analyse :
- Exemple : `https://riftaffinity.vercel.app/duo/Faker-KR1/Keria-T1`
- Prévisualisation automatique (OpenGraph cards) pour Discord, Twitter & WhatsApp.

### 4. 🤖 Bot Discord RiftAffinity
> Un bot Discord permettant de calculer l'affinité directement dans n'importe quel serveur :
- Commande : `/affinity player1:Faker#KR1 player2:Keria#T1`

### 5. 🏆 Classement des Meilleurs Duos (Leaderboard)
> Afficher les duos ayant le plus haut score d'affinité enregistrés sur le site.
